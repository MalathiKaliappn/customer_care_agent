# Tesla_RAG_Chatbot

# 🚗 Tesla Model S Manual Assistant (RAG + Streamlit)

A simple, containerized app that lets you upload a Tesla Model Y manual (PDF), processes it using Retrieval-Augmented Generation (RAG).

Built with:
- [LangChain](https://www.langchain.com/)
- HuggingFace Transformers for embeddings
- LLaMA3 via [GROQ](https://console.groq.com/)
- FAISS vector store
- Docker + Docker Compose
- Streamlit
